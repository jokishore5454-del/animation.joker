How live updates work

  1. Upload media here.
  2. The file is stored in Supabase Storage and the public site's live configuration is updated.
  3. Visitors get the new media on their next config refresh; no Netlify rebuild is required.

Tip: Keep hero video under about 20–30 MB and use MP4/H.264 for best browser compatibility.
